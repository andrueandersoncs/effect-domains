# Effect Domains

Effect Domains explores how applications can use Effect Schemas as rich domain models and safely derive mechanical, lossless representations from them.

The project is currently testing this idea through narrow vertical slices. Business policy, state transitions, authorization, transactions, migrations, and compatibility remain explicit authored concerns.

## Documentation

The persistent project wiki starts at [docs/wiki/README.md](docs/wiki/README.md). It contains the maintained thesis, validation strategy, research agenda, and immutable source material.

## Development

Install dependencies:

```bash
bun install
```

Run the current entry point:

```bash
bun run index.ts
```
